# E. Sousa - Composer & Violinist

Official website of Portuguese composer and violinist Eduardo Neves de Sousa, based in Oslo, Norway.

🌐 **Website:** https://esousaofficial.com/

## About the Project

This repository contains the source code for the official website of E. Sousa.

The website was designed and developed as a custom, lightweight PHP website, with a focus on presenting Eduardo's work as a composer and violinist through a cinematic and editorial visual language.

It brings together original music, film scoring work, collaborations, biography, press materials and professional contact information.

## Features

- Responsive and mobile-first layout
- Custom PHP-based page structure
- Clean URL routing with Apache `.htaccess`
- Structured metadata and Schema.org markup
- Open Graph and social sharing metadata
- XML sitemap and `robots.txt`
- Custom 404 page
- Lazy-loaded YouTube video embeds
- Responsive image handling
- Accessibility and reduced-motion considerations
- Semantic HTML structure
- SEO-oriented page architecture
